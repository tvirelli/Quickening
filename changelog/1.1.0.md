**New**

- Compare before you delete. The side-by-side preview now handles far more than
  photos: images (including WebP and SVG), video with thumbnails, audio with a
  real waveform, PDFs, code with syntax highlighting, Markdown, plain text, and
  even a listing of what's inside ZIP and TAR archives. Anything without a
  built-in preview can be opened in its default app straight from Quickening.
- "Created together" safety. When duplicate copies were all created in the same
  instant — the signature of a camera burst or an export batch — Quickening flags
  them, leaves them out of the recommended selection, and asks for an extra
  confirmation before removing them.
- Real Windows file-type icons in the results list, so files are easier to
  recognize at a glance.
- "Open file" and "Open file location" added to the results right-click menu.

**Fixes**

- Fixed a hang: opening certain stylesheet files (.css / .less / .scss) in the
  preview could make the app stop responding. It no longer does.
- Some video clips reported a wildly wrong length (hours for a clip only seconds
  long); the duration now corrects itself.
