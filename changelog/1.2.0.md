**New**

- Redesigned the results filters into a tidy left sidebar. Everything now lives
  in one rail — category, size, modified date, path, copies, and extension —
  instead of crowding the top of the list.
- Filter by more than one category at once. Category is now a checklist with a
  live file count next to each type; tick as many as you like, or "All" to clear.
- Filter by file extension. The Extension dropdown lists only the types that
  actually appear in your results, so every choice shows something.
- Nicer filter controls: pick dates from a calendar, choose a minimum number of
  copies from a dropdown, and set size with a value plus an MB/GB unit.

**Fixes**

- The filter inputs now match the app's dark theme, with centered placeholder
  text and no stray field chrome.
