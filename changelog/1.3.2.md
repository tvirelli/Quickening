**Improved**

- Quickening now tells you when an update is ready. A banner at the top of the
  window says a new version has downloaded, with a **Restart to update** button
  that installs it and reopens Quickening in a few seconds.
- If Quickening is running in the tray, you get a Windows notification with the
  same Restart to update button.
- Prefer to wait? Close the banner and the update installs quietly the next
  time Quickening closes, with no installer window popping up.
- Restart to update waits if a scan or a removal is running, so nothing is cut
  off halfway.
- Quickening that stays open for days now checks for updates every few hours,
  not only when it starts.
