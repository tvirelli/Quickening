**New**

- Find more than exact copies. Turn on Advanced Options to also find similar
  photos (resized, re-saved, or lightly edited copies), blurry photos, the same
  song saved in different formats or bitrates, and near-duplicate videos.
- "Keep best" for similar photos picks the copy worth keeping: highest
  resolution, then the sharper shot, then the original format over a re-saved
  JPEG. A badge on the keeper says why.
- Tidy up: find empty folders and zero-byte files and clear them out in one go.
- Duplicate folders: spot whole folders that are exact copies of each other.
- Ignore files or folders you keep on purpose (right-click any file). Ignored
  items are hidden from results and can never be selected or deleted. Manage
  them in Settings.
- One results page with collapsible sections for every kind of match, and a
  SHOW checklist to choose which sections you see.
- File dates now show the time down to the second, so you can see exactly which
  copy is newest.
- Clear just one end of the Modified date filter with its own ✕.

**Fixes**

- Fixed a crash a few seconds after using Undo.
- "Rescan at 50 MB" now actually rescans, and no longer blocks every scan after
  it until you restart.
- Exported CSV files show dashes and accented characters correctly in Excel.
- Esc closes the side-by-side preview.
- Screen readers now announce file names, checkboxes, and switches properly.
- After Undo, the screen tells you your files are back, and the Recycle Bin
  count updates straight away.
- The window can no longer be shrunk so small that file names disappear.
